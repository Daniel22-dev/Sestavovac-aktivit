# ACTIVA 0.5.1

## Oprava pilotního měření

- Úspěšně vytvořený materiál se zapisuje do AI Studia jako jediný povolený typ `activity-pack`.
- Neúspěšný pokus o vytvoření materiálu se zapisuje jako neúspěšný `activity-pack`.
- Tisk, HTML a sdílecí export už tentýž materiál znovu nezapočítávají.
- Přidána regresní kontrola zakazující staré nepovolené názvy výstupů.
- Minimální kompatibilní verze AI Studia je 0.18.5.

Funkce, vzhled a pracovní postup ACTIVA se jinak nemění.
